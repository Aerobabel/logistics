# Logistics App User Guide

## Counterparties (Контрагенты)

### Adding a New Counterparty
1. Navigate to the **Contragents** section via the sidebar.
2. Click the **+ Add (Добавить)** button in the top right.
3. Fill in the required fields (Name, Type, INN, etc.).
4. Click **Create Counterparty**.

### Editing a Counterparty
1. In the **Contragents** list, click on a counterparty card to view details.
2. In the details view, click the **Edit** button (next to the status badges).
3. Modify the information in the form.
4. Click **Save Changes**.

### Deleting a Counterparty
*Note: Deleting is available via the API but currently restricted in the UI to prevent accidental data loss. Contact admin for deletion.*

## Logistics (Requests)

### Creating a New Delivery Request
1. Navigate to the **Logistics (Requests)** section.
2. Click the **+ New Delivery** button.
3. Fill in the form (Date, Cargo, Route, Cost).
4. Click **Create Request**.

### Editing a Request
1. In the **General Logistics** tab, find the request card.
2. Click the **Pencil icon** on the card.
3. Update the details in the dialog.
4. Click **Save Changes**.

### Deleting a Request
1. In the **General Logistics** tab, find the request card.
2. Click the **Trash icon** (Red).
3. Confirm the deletion in the popup.

## Managers

### Adding a Manager
1. Navigate to the **Managers** section.
2. Click **+ Add Manager**.
3. Enter the manager's name.
4. Click **Add**.

## Troubleshooting
If you encounter issues, ensure the database is running and accessible. Relogin if authentication errors occur.
